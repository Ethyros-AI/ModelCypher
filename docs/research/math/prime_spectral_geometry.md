## Time-Delay Embedding (Takens Theorem)

### The Problem

Prime gaps form a 1D sequence: `[2, 2, 4, 2, 4, 2, 4, 6, ...]`

Direct analysis sees only local values. **Time-delay embedding** lifts this to higher dimensions where structure becomes visible.

### The Construction

Given sequence $(x_1, x_2, ..., x_n)$ and embedding dimension $d$:

$$X = \begin{pmatrix} x_1 & x_2 & \cdots & x_d \\ x_2 & x_3 & \cdots & x_{d+1} \\ \vdots & & \ddots & \vdots \\ x_{n-d+1} & x_{n-d+2} & \cdots & x_n \end{pmatrix}$$

Each row is a "window" of $d$ consecutive values.

### Takens' Theorem

If the sequence is generated by a dynamical system with attractor of dimension $D$, then for $d > 2D$, the time-delay embedding is diffeomorphic to the original attractor.

**Implication**: The topology of the underlying system is preserved in the embedded space.

### For Prime Gaps

If prime distribution has hidden low-dimensional structure (e.g., from the Riemann zeta zeros), time-delay embedding should reveal it as concentrated eigenvalue spectra.

## Gram Matrix Analysis

### Definition

For embedded data $X \in \mathbb{R}^{n \times d}$, the **Gram matrix** is:

$$K = X X^T \in \mathbb{R}^{n \times n}$$

Entry $K_{ij} = \langle x_i, x_j \rangle$ is the inner product between rows $i$ and $j$.

### Why Gram Matrices?

1. **Dimension-independent**: K has shape $(n, n)$ regardless of feature dimension $d$
2. **Captures relational geometry**: All pairwise similarities
3. **Invariant to rotation**: If $Y = XR$ for orthogonal $R$, then $YY^T = XRR^TX^T = XX^T = K$

### Eigenvalue Decomposition

Since $K$ is symmetric positive semi-definite:

$$K = U \Lambda U^T$$

where $\Lambda = \text{diag}(\lambda_1, \lambda_2, ..., \lambda_n)$ with $\lambda_1 \geq \lambda_2 \geq ... \geq \lambda_n \geq 0$.

The eigenvalues encode the **effective dimensionality** of the data.

## Spectral Metrics

### Participation Ratio

The **participation ratio** (effective rank):

$$\text{PR} = \frac{(\sum_i \lambda_i)^2}{\sum_i \lambda_i^2}$$

**Interpretation**:
- PR = 1: All variance in one eigenvalue (1D structure)
- PR = n: Uniform variance across all eigenvalues (full rank)

**For primes vs random**: Lower PR suggests more concentrated structure.

### Spectral Entropy

The **spectral entropy**:

$$H = -\sum_i p_i \log p_i, \quad p_i = \frac{\lambda_i}{\sum_j \lambda_j}$$

**Interpretation**:
- H = 0: One dominant eigenvalue
- H = log(n): Uniform spectrum

Lower entropy = more concentrated spectrum = more structure.

### Top-k Ratio

$$R_k = \frac{\sum_{i=1}^k \lambda_i}{\sum_j \lambda_j}$$

Typically $k = 10$. Higher $R_k$ = more variance in top eigenvalues.

### Condition Number

$$\kappa = \frac{\lambda_{\max}}{\lambda_{\min}}$$

High condition number indicates ill-conditioning (near-singular structure).

## Connection to Random Matrix Theory

### Marchenko-Pastur Law

For a random matrix $X \in \mathbb{R}^{n \times d}$ with i.i.d. entries from $N(0, \sigma^2/d)$:

The eigenvalues of $\frac{1}{n}XX^T$ converge to the Marchenko-Pastur distribution:

$$\rho(\lambda) = \frac{\sqrt{(\lambda_+ - \lambda)(\lambda - \lambda_-)}}{2\pi \gamma \lambda}$$

where $\gamma = d/n$ and $\lambda_{\pm} = \sigma^2(1 \pm \sqrt{\gamma})^2$.

### Departure from MP

Structured data **departs** from MP:
- Heavy tails (outlier eigenvalues)
- Spectral gaps
- Lower participation ratio

**For primes**: If they depart from MP more than random gaps, this suggests genuine structure.

### Montgomery's Conjecture

Montgomery (1973) showed that normalized spacings between Riemann zeta zeros follow:

$$P(s) = 1 - \left(\frac{\sin(\pi s)}{\pi s}\right)^2$$

This is the **GUE pair correlation** (Gaussian Unitary Ensemble from random matrix theory).

**Connection**: If primes have structure related to zeta zeros, their Gram matrix eigenvalues may show GUE statistics.

## Statistical Comparison

### Wasserstein Distance (Earth Mover's Distance)

For cumulative distributions $F_1, F_2$:

$$W_1(F_1, F_2) = \int_{-\infty}^{\infty} |F_1(x) - F_2(x)| dx$$

Measures the "work" to transform one distribution into another.

### Kolmogorov-Smirnov Statistic

$$D = \sup_x |F_1(x) - F_2(x)|$$

Maximum pointwise difference between CDFs. KS > 0.1 suggests meaningfully different distributions.

### Permutation Test

To compute p-values without distributional assumptions:

1. Compute observed difference $\Delta_{\text{obs}} = |\bar{x}_1 - \bar{x}_2|$
2. Combine samples and randomly permute $N$ times
3. For each permutation, compute $\Delta_{\text{perm}}$
4. p-value = fraction of permutations where $\Delta_{\text{perm}} \geq \Delta_{\text{obs}}$

## The Cramér Model

### Definition

In Cramér's probabilistic model, each integer $m > 1$ is independently "prime" with probability:

$$P(m \text{ is prime}) = \frac{1}{\ln m}$$

This captures the **average density** of primes (Prime Number Theorem) but not correlations.

### Gaps in Cramér Model

Expected gap near $n$: $\approx \ln n$

The Cramér model produces gap sequences that match prime statistics locally but lack the fine structure from the Riemann zeta function.

### Testing Against Cramér

If primes differ from Cramér model gaps, the difference must come from:
- Correlations in prime distribution
- Structure from zeta zeros

## Implementation Notes

### Backend Protocol

All computations use the `Backend` protocol for GPU acceleration:

```python
# CORRECT - Backend protocol
from modelcypher.core.domain._backend import get_default_backend
backend = get_default_backend()

gram = backend.matmul(X, backend.transpose(X))
eigenvalues, _ = backend.eigh(gram)
```

### Numerical Stability

1. **Eigenvalue filtering**: Ignore eigenvalues < 1e-10 for ratio computations
2. **Log safety**: Use `log(x + eps)` for entropy
3. **Gram normalization**: Multiply by 1.0 to ensure float dtype

### Complexity

| Operation | Complexity |
|-----------|------------|
| Time-delay embedding | O(n * d) |
| Gram matrix | O(n² * d) |
| Eigendecomposition | O(n³) |
| Full analysis | O(n³) bottleneck |

For n = 10,000 primes with d = 20: < 1 minute on GPU.
